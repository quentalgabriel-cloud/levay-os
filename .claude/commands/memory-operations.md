# Memory Operations

Mapeia as operações atuais do negócio (o que está rodando hoje).

## Descrição

Coleta e documenta:
- Quais processos estão ativos
- Quem é responsável por cada área
- Quais sistemas/ferramentas são usados
- Volume/tamanho das operações
- Status de cada operação (funcionando, precisa melhorar, quebrado)

## Ação

Executar análise de "estado atual" com perguntas como:
- Quais são as principais áreas do negócio?
- O que roda todo dia/semana?
- Quais ferramentas/sistemas são usados?
- Quem faz o quê?

## Saída

Gera arquivo `.memory/operations/overview.md` com mapeamento completo.
