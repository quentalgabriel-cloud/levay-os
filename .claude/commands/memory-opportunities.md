# Memory Opportunities

Identifica novas frentes e oportunidades de crescimento/melhoria.

## Uso

/memory opportunities [area]

## Descrição

Analisa uma área específica e identifica:
- Oportunidades de automatização
- Novas frentes de negócio
- Melhorias em processos
- Expansão de serviços
- gaps de conhecimento/ferramentas
- Integrações possíveis

## Exemplos

```
/memory opportunities
/memory opportunities vendas
/memory opportunities operações
```

## Saída

Gera arquivo em `.memory/opportunities/` com:
```markdown
---
title: Oportunidade
type: opportunity
impact: alto
effort: medio
tags: [area, automacao]
connections: [processo-relacionado]
created: 2026-05-12
---

# Oportunidade

## Descrição
[O que é]

## Benefício
[O que resolve ou agrega]

## Estimativa de Esforço
[Quanto trabalho para implementar]

## Próximos Passos
[Ações para validar/executar]
```
