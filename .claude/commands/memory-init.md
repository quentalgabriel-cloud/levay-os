# Memory Init

Inicializa a estrutura de memória organizacional na raiz do projeto.

## Descrição

Cria a estrutura `.memory/` com:
- `purpose.md` - Missão, objetivos e perguntas-chave do negócio
- `schema.md` - Regras de estrutura da memória
- `log.md` - Registro cronológico
- `entities/` - Entidades identificadas
- `processes/` - Processos mapeados
- `bottlenecks/` - Gargalos identificados
- `opportunities/` - Novas frentes
- `operations/` - Operações atuais

## Pré-requisitos

- Este comando só deve ser executado com contexto claro sobre o negócio
- Ideal para projetos que estão começando a documentar operações

## Ação

Execute o comando e colete informações sobre:
1. Qual é o negócio? (produto/serviço)
2. Quais são as áreas principais?
3. Quais são os objetivos de curto/médio prazo?
4. Quais perguntas-chave o sistema deve responder?

## Resultado

Estrutura `.memory/` criada com arquivos base.
