## Story

**As a** comercial da AMP 213,
**I want** captar leads automaticamente via webhook,
**so that** nenhuma oportunidade se perca por atraso de cadastro.

## Acceptance Criteria

1. Endpoint recebe webhook n8n com validacao de assinatura.
2. Payload valido cria lead com origem/campanha e timestamp.
3. Payload invalido retorna erro padronizado sem persistencia.
4. Falhas de processamento ficam registradas para reprocesso.
5. Testes cobrem assinatura, ingestao e erros de validacao.
