## 2. Integration Approach

**Principle:** INTEGRATE, don't replace. The existing architecture is solid.

### 2.1 What We Created

| File | Purpose | Integration |
|------|---------|------------|
| `tenant-context.ts` | Workspace-based tenant context + permissions | Uses existing `workspace_members` |
| `dashboard-metrics.ts` | Company-scoped metrics for cockpit | Uses existing tables |
| `middleware.ts` (updated) | Workspace context headers | Adds `x-workspace-id`, `x-user-role` |
| `auth/callback/route.ts` (updated) | Audit logging on login | Uses existing `audit_log` table |
| `auth/logout/actions.ts` | Logout with audit | Uses existing `audit_log` table |
| `docs/architecture/levay-os-existing-architecture.md` | Architecture documentation | Reference for team |

### 2.2 What We Did NOT Create (Avoiding Duplication)

| Avoided | Reason |
|---------|--------|
| New Tenant model | Use existing `companies` |
| New User-Tenant table | Use existing `workspace_members` |
| Duplicate auth flow | Existing Supabase auth is functional |
| Prisma schema (outside /prisma/) | Existing Supabase handles schema |

## 3. Implementation Summary

### 3.1 Tenant Context (`tenant-context.ts`)

```typescript
// Uses existing workspace_members table
export interface TenantContext {
  workspaceId: string   // from workspaces.id
  userId: string        // from Supabase Auth
  userRole: WorkspaceRole // owner | admin | member | viewer
  workspaceName: string
  workspaceSlug: string
  isOwner: boolean      // role === 'owner'
  isAdmin: boolean      // role === 'owner' || 'admin'
}

// Permissions based on workspace role
export function canManageUsers(ctx): boolean
export function canCreateTasks(ctx): boolean
export function canManageFinance(ctx): boolean
export function canViewAuditLog(ctx): boolean
```

### 3.2 Dashboard Metrics (`dashboard-metrics.ts`)

```typescript
// Company-scoped metrics for multi-tenant cockpit
export async function getCompanyMetrics(
  workspaceId: string,
  companyId: string,
  companySlug: string,
  companyName: string,
  companyColor: string | null
): Promise<CompanyMetrics>

// Workspace-level dashboard
export async function getWorkspaceDashboardMetrics(
  workspaceId: string
): Promise<WorkspaceDashboardMetrics>

// Cockpit blocks for Mesa do Diretor
export async function getCockpitBlocks(
  workspaceId: string,
  companySlug?: CompanySlug
): Promise<CockpitBlock[]>
```

### 3.3 Middleware Enhancement

```typescript
// Added context headers
```
