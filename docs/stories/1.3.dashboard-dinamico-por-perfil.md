## Story

**As a** CEO/comercial/operações,
**I want** ver dashboards diferentes conforme meu papel,
**so that** eu tenha contexto relevante para tomada de decisão.

## Acceptance Criteria

1. Usuário com perfil CEO visualiza dashboard macro com KPIs consolidados cross-tenant autorizados.
2. Usuário com perfil comercial visualiza funil, leads sem resposta e pendências de follow-up.
3. Usuário com perfil operações visualiza filas de execução, exceções e Quality Gates pendentes.
4. O sistema aplica regras de visibilidade por papel e `tenant_id` em todos os blocos do dashboard.
5. Componentes do dashboard carregam estado de erro/sem dados sem quebrar a navegação.
6. Testes automatizados validam roteamento por perfil, isolamento por tenant e conteúdo mínimo por visão.
