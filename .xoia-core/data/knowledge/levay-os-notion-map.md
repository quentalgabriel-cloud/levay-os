> Extraído em 2026-05-12. Fonte: Notion do Erick.

## Visão Geral
O LEVAY OS é o "sistema operacional" das empresas do Erick, centralizando:
tarefas, projetos, decisões, processos, biblioteca, perfis, IA e rituais de escuta.

## Implicações para o Sistema Digital

### Multi-Tenant
- `sollu` → Tenant isolado (CRM, Billing, Contratos)
- `bica` + `amp213` → Tenants com operação compartilhada (Events, Reservations, Membership)

### Dashboard Roles
- **CEO (Erick)** → "Mesa do Diretor" = Dashboard consolidado multi-tenant
- **Comercial** → Foco em CRM Sollu + Billing
- **Operações** → Foco em Quality Gates + Events + Reservations

### Rituais Operacionais
O sistema deve suportar:
1. Revisão matinal (Dashboard diário)
2. Delegação automatizada (Workers)
3. Feedback loops (Pulso da Equipe)
4. Quality Gates (aprovação humana antes de ações críticas)
