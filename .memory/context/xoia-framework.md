# XOIA Framework

Meta-framework que orquestra agentes AI especializados para soluções digitais de agências de marketing.

## Filosofia

O usuário descreve o que precisa e o XOIA executa o ciclo completo automaticamente.

## The Cycle

```
PLAN → BUILD → CHECK → SHIP
```

## Modos

- **Quick**: Bug fix, ajuste, config, hotfix
- **Standard**: Feature, landing page, integração
- **Deep**: Arquitetura nova, brownfield, sistema complexo

## Agentes

| Agente | Persona | Expertise |
