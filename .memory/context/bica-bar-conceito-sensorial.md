# Bica Bar Sensorial — Conceito e Posicionamento

## Identidade

| Atributo | Detalhe |
|----------|---------|
| **Nome** | Bica Bar Sensorial |
| **Conceito** | Speakeasy — bar de experiência premium |
| **Localização** | 2º piso do AMP 213, Rua do Amparo 213, Olinda |
| **Horário** | Quinta a Sábado, 19h às 01h |
| **Lotação** | 65 pessoas sentadas minimamente confortáveis |

## Elementos Distintivos

### Atmosfera

| Elemento | Descrição |
|----------|-----------|
| **Iluminação** | Luz baixa — ambiente intimista, não utilitário |
| **Estética** | Rustico/chique — contraste entre o antigo (prédio histórico) e o premium |
| **Características** | Contrastes contemporâneos — mix de elementos clássicos com linguagem moderna |

### Experiência

- Não é apenas um bar — é uma **experiência sensorial**
- Foco em **qualidade, não volume**
- Diferenciação pela experiência (não apenas drinks)

## Potencial Identificado

### Eventos Experimentais

> "O espaço aparenta ter bastante potencial para eventos experimentais em outros formatos"

Este é um **diferencial competitivo** não explorado:
- Eventos além do formato bar tradicional
- Experiências imersivas
- Collabs com artistas/curadores
- Noites temáticas
- Degustações comentadas
- Bastidores/experiências de chefs

### Oportunidades de Revenue

| Formato | Exemplo |
|---------|---------|
| Experiências temáticas | Noites de jazz, vinil, degustação |
| Eventos privados | Reservas exclusivas para grupos |
| Collabs | Bartenders convidados, marcas premium |
| Membership | BICA CLUB — acesso prioritário |

Permite:

## Arquitetura no Levay OS

No sistema, o Bica Bar é um **módulo ERP completo**:

| Módulo | Função |
|--------|--------|
| **Reservas** | Gestão de mesas, capacidade, fila de espera |
| **Orders/PDV** | Pedidos, komanda, fechamento |
| **Estoque** | Controle de bebidas, alertas mínimos |
| **Menu/Cardápio** | Drinks, preços, descrição sensorial |
| **Checklists** | Abertura, fechamento, qualidade |
| **Membership** | BICA CLUB — programa de benefícios |
| **Alertas** | Estoque mínimo → WhatsApp fornecedores |

### Integração com AMP 213

- Compartilha equipe (garçons, limpeza)
- Eventos no salão podem afetar operação do bar
- Coordenação de calendário necessária
