# Overview de Operações

## Como Preencher

Execute `/memory operations` para iniciar o mapeamento. O sistema fará perguntas sobre:
- Áreas principais do negócio
- Processos críticos
- Sistemas e ferramentas utilizadas

## Estrutura de Operações

- **áreas**: Times e departamentos
- **processos**: Fluxos de trabalho
- **sistemas**: Ferramentas utilizadas
- **status**: Funcionando / precisa melhorar / quebrado

## Comandos Relacionados

- `/memory bottlenecks` — Identificar gargalos
- `/memory opportunities` — Descobrir oportunidades
- `/memory analyze [tema]` — Analisar área específica

---

*Use `/memory operations` para iniciar o mapeamento completo*
